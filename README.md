# LinkData

Link Engineering Company 的链接数据分析项目。

## 项目概述

本项目包含用于分析链接数据的工具和文档。

## 文件说明

- **LinkData.htm** - 链接数据文档（由 Microsoft Word 生成，包含约 14000+ 单词的技术资料）
- **LinkData_VB.dll** - Visual Basic 动态链接库（32 位版本）
- **LinkData_VB64.dll** - Visual Basic 动态链接库（64 位版本）

## 技术细节

- 数据来源：Link Engineering Company
- 文档创建时间：2000 年 3 月
- 最近更新时间：2021 年 10 月
- 文档页数：约 39 页

## 使用方法

根据您的需求，使用相应的 DLL 文件进行链接数据分析。

## 注意事项

- 请根据您的系统架构选择合适的 DLL 文件（32 位或 64 位）
- HTM 文件包含完整的链接数据参考资料
